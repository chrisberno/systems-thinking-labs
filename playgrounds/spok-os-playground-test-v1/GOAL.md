# GOAL — spok-os-playground-test-v1

## Project Goal (persistent)

Build a single-page **Next.js** site that renders the **SPOK OS onion** and explains each of the
four rings (**Agent · Brain · Capabilities · Connectors**) in plain terms — a self-referential
proof: *use SPOK OS to ship a site about SPOK OS.*

## Definition of done

- `npm install && npm run dev` serves a clean page at `localhost:3000` with **no build errors**.
- The page shows the **four-ring onion** (reuse `spok-ai-os-v2.svg` from the SPOK OS model dir) +
  one short blurb per ring + the manifesto tagline (*"Own the soul. Ship the OS."*).
- Responsive and legible.

> Set per session. e.g. *"scaffold the landing page and drop in the onion SVG."*
